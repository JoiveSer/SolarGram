# SolarGram Desktop — Ультимативный каталог функций экосистемы Telegram (Desktop / iOS / Android)

> [!NOTE]
> **Охват аудита:** изучены 3 официальных корневых репозитория (`tdesktop`, `telegram-ios`, `Telegram-Android`), все прямые форки `>= 3★` (`59` Desktop + `31` iOS + `78` Android = `168`), расширенный срез форков 2-го поколения `>= 3★` и отделившихся клиентов (`229` записей в основном индексе: `83` desktop, `107` android, `35` ios, `3` base, `1` macOS), а также `16` standalone-клиентов (итого `245` записей с учётом пересечений).
> В самом **SolarGram Desktop** весь базовый стек и сторонние упоминания приведены к брендингу `SolarGram` с удалённой внешней телеметрией (`Sentry`, CDN-манифесты, боты пробива даты регистрации); ниже сохранён полный исследовательский каталог открытых источников для планирования модулей комбайна. Текущий статус реализации в коде см. в [COMBINE_ARCHITECTURE.md](COMBINE_ARCHITECTURE.md) и [README-RU.md](../README-RU.md).

> [!IMPORTANT]
> **Легенда приоритета для Windows-комбайна:**
> - `[Desktop OSS]` — уже реализовано в open-source форке `tdesktop` / Windows-клиенте (можно брать патч/код напрямую).
> - `[Порт с Mobile]` — уникальная механика iOS/Android-форков, перспективная для переноса на Windows.
> - `[Security / Audit]` — критично для защиты пользователя или требует устранения уязвимостей перед включением.

## 12. Официальные клиенты (tdesktop / iOS / Android): база + кандидаты на кросс-платформенный перенос

По результатам проверки актуальных веток официальных клиентов (`tdesktop v7.4.4`, `telegram-ios release-13.2`, `Telegram-Android 13.2.2`):

### Уже есть в свежем официальном `tdesktop` (не нужно писать заново в комбайне)
- **HTML-виджеты в ботах** (`v7.4`) — **внимание `[Security]`**: форк [opengram](https://github.com/recultivationorg/opengram) отключал аналогичный функционал из-за риска RCE, а [tdesktop v7.4.4](https://github.com/telegramdesktop/tdesktop) уже внёс ограничители квоты хранения виджетов и лимиты парсинга PNG/групп; обязателен аудит изоляции WebView перед использованием.
- **Rich Text Editor (WYSIWYG), таблицы, формулы, чеклисты, отложенный ввод AI-стриминга и цитирование rich-сообщений** (`v7.0.5–v7.3.2`).
- **TON Wallet / Money card + кастомизация коллекционными подарками + крафт подарков из видеостикеров + кастомные QR публичных юзернеймов** (`v7.2.6–v7.3.3`).
- **Вкладки глобального поиска** (Приложения / Каналы / Посты / Медиа) + анимация полёта текста в пузырь (`v7.3.4`).
- **Перетаскивание папки/набора файлов одним архивом** + редактор GIF с подписью и оценкой размера видео на таймлайне (`v7.2.6`).
- **Камера и микрофон для Mini Apps на Windows и macOS** (`v7.3.5`).
- **Native QT 6 на Windows** (`v7.3.2`) + встроенный `TranslateProvider` API с поддержкой URL-бэкендов (`v7.2.9+`).

### Мобильные/экспериментальные возможности для добора на Windows Desktop
1. **Публикация, редактирование и черновики Историй (Stories) на ПК** — уже прототипировано и работает в [freshGram](https://github.com/Snowy-Fluffy/freshGram).
